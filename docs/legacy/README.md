# Documentos antigos (visão, não implementação)

Os arquivos desta pasta são a primeira visão da linguagem de script e da "biblioteca" do Saga Engine:

- `SAGA_ENGINE_SCRIPT_SES.md`: um rascunho grande de linguagem (com sistemas globais, UI, áudio...).
- `SAGA_LIBRARY_V2.md` e `SAGA_LIBRARY_V3.md`: o manual que a IA recebia no prompt.

Quase nada disso foi implementado, e esses textos chegaram a ir inteiros (86 KB) no prompt da IA,
que inventava comandos que não existiam. Ficam aqui como registro de ideias para o futuro.

A linguagem que existe de fato, com parser, testes e erros com linha e coluna, está em
[`docs/SES.md`](../SES.md).
